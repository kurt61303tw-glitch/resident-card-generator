# 個案資料卡產生器

純前端的個案資料卡製作工具，可在瀏覽器中整理資料並匯出 PDF、Word 與 PowerPoint。

## 資料與 AI 使用提醒

- 本儲存庫不包含個案資料、使用者 API Key、舊版備份或內部測試檔。
- 基本表單與匯出功能在瀏覽器端運作。
- AI 功能由使用者自行輸入 Gemini API Key 啟用；啟用並送出分析時，使用者選擇的文字、照片或文件會由該瀏覽器直接傳送至 Google Gemini API。
- 請勿在未確認機構規範、個資授權與資料處理條件前，上傳可識別的照護或健康資料。

## 本機使用

直接開啟 `index.html`，或以任一靜態網站伺服器提供此資料夾。GitHub Pages 版本可從網站設定中的 Pages 區塊取得公開網址。
